# hardware/ — машиночитаемые и визуальные данные платы retro_PCLD_board V2

Экспорт из EasyEDA (проект **CPLD_108_for_retro V2**, дата экспорта 2026-10-20) для платы
retro_PCLD_board V2 (Intel 8085 + CPLD XC95108). Словесным эталоном схемы остаётся
[SCHEMATIC.md](../SCHEMATIC.md) в корне репозитория; файлы здесь — экспорты того же проекта
в стандартных форматах.

  EasyEDA; это одна и та же плата.
- Не включены (есть в поставке экспорта, добавляются по решению владельца): исходник

  U10 A29040B (flash 512K×8).
