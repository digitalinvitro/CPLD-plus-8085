# Линия hiclock — v3.9.9h (CPU 4,167 МГц)

Линия повышенной тактовой частоты процессора. База — **v3.9.8** (beta/lowsize,
подтверждена владельцем на железе: стабильно, зависаний нет). **Единственная
переменная — длина кольца one-hot: N=7 → N=6**; всё остальное байт-в-байт
(clk25 = /2 для логики, por-цепь 50-домена, GSR п.18/20, хардренинг RST п.21,
TX v3.7, автомат шины, legacy-ветки делителя).

## Частотные параметры v3.9.9h

| Параметр | v3.9.8 (N=7) | **v3.9.9h (N=6)** |
|---|---|---|
| Вход CPLD (GCK3, H1 без шунта) | 50 МГц | 50 МГц |
| Кольцо | r0..r6, период 140 нс | **r0..r5, период 120 нс** |
| X1 = r0 | 7,143 МГц, duty 1/7 (20/120) | **8,333 МГц, duty 1/6 (20/100)** |
| X2 | r1\|..\|r6 = ~X1 (6 ПТ) | **r1\|..\|r5 = ~X1 (5 ПТ)** |
| CPU (внутренний /2 ВМ85А) | 3,571 МГц, T=280 нс | **4,167 МГц, T=240 нс** |
| Логика (clk25) | 25 МГц | 25 МГц (без изменений) |
| POR = 8 x период кольца | 1120 нс | **960 нс** (норма 3 CLK = 720 нс, запас 1,33x — тот же) |
| Снятие por_run (штатный старт) | 1020 нс | **880 нс** (<= 980 нс из любого кода) |
| Терминал (бод = 1920 x f_CPU) | 6857 8N1 | **8000 8N1** (48000/6 ровно) |
| Зазор WR#(вверх)->след.ALE | 70..126 нс | **60..108 нс** (окно WB тоньше — см. риски) |
| Прогноз МЦ | 94/108 (факт) | **93/108** (ПТ -2..3: X2 5 ПТ, NOR6) |

## Состав

- `top_suart_hiclock_v399.v` (CP1251 — для ISE) + `top_suart_hiclock_v399_utf8.v`;
- `scripts/gen_v399h.py` — генератор из v3.9.8 (28 span-замен, каждая РОВНО 1 раз;
  негативные контроли RTL-зоны: r6/NOR7/7,143/140 нс/1120 — отсутствуют;
  позитивные: уравнения r0..r5, X2 5-ПТ, NOR6, 4,167, 960 нс; round-trip CP1251);
- `scripts/sim_v399h_ring6.py` — полный перебор модели узла: 64 кода кольца →
  one-hot ≤ 2 фронтов (макс = 2), орбита периода 6; power-on 64x8x2 = 1024
  комбинации; негативные контроли: наивное кольцо ходит вечно, одинарный kill
  (v3.8) на N=6 орбитит 22/64 кода — двойной kill НЕОБХОДИМ и ДОСТАТОЧЕН;
- `scripts/tb_poweron_v399h.v` + `run_tb_poweron_v399h.sh` + `tb_poweron_v399h.log`.

## Верификация (Icarus 12.0, RTL v3.9.9h)

- ЭЛАБОРАЦИЯ: все 5 веток generate компилируются, 0 ошибок;
- **P0a PASS**: 1280 комбинаций (64 кольца x 10 por_sh x 2 фазы clk25) —
  one-hot ≤ 2 фронтов из ЛЮБОГО кода; дрейн por_sh в 00 ≤ 1400 нс навсегда;
  por_run падает и не возвращается; clk25_q тогглится 640/640;
- **P0b PASS**: орбита FF→7F→3F→1F→0F→07→03→01→00 монотонная, без возврата;
- **PX PASS**: 50 фронтов X1 с шагом РОВНО 120 нс, high РОВНО 20 нс
  (duty 100/600 = 1/6 точно), X2 == ~X1 в каждом сэмпле, por_ce — РОВНО один
  строб за 120 нс; RESET_IN снялся через 900 нс (модель: 880 + кромка clk25);
- **P1**: 1 «ошибка» ЭТАЛОННОГО класса (сид 84, /WE ровно на 200 нс, граница
  порога). Эталон v3.9.8 в тот же день тем же методом — 3 «ошибки» (сид
  74/92/96 на 160–200 нс) — задокументированный самозаживляющийся класс окна
  40 нс (анатомия v3.9.6+ 11-6/11-7; путь сброса байт-в-байт v3.9.8, окно НЕ
  расширялось). Самозаживление 100/100 (89+11), экспозиция уже эталона
  (грязь 50/100 против 57/100);
- **P2/P3/P4/P5 PASS**: мёртвый clk (жалоба 11-6bis воспроизводится так же),
  поздний clk ≤ 1400 нс, RST=1 лечится отпусканием (420 нс), лотерея
  передёргиваний — геометрия «рано или поздно».

## Риски и откаты

1. **CPU 4,167 МГц** — экземпляр ИМ1281ВМ85А: 5,0 не тянул (п.15), 4,167 = 83%
   предела, в ТУ. Откат по частоте — v3.9.8 (N=7, 3,571 МГц), одна перемычка
   не нужна, только прошивка;
2. **Окно writeback тоньше**: окно T1H ~76..164 нс (2..4 тика 25 МГц) против
   120..220 у v3.9.8. После фита ПЕРЕИЗМЕРИТЬ зазор WR#→ALE осциллографом и
   прогнать PUSH-стресс (запись стека). При T=200 (5 МГц, эпоха v3.8) FSM был
   жив — срывал сам CPU;
3. High X1 = 20 нс — ТОТ ЖЕ, что у v3.9.8 (подтверждено железом). Откат по
   duty одной строкой RTL: `X1 = r0 | r1` (high 40 нс), частоты те же.

## Что делать владельцу

1. Фит в ISE: `top_suart_hiclock_v399.v` (CP1251, Set as Top Module), UCF БЕЗ
   правок, опции как у v3.9.8 (Pterm 18, Exhaustive OFF; IL 16/28 — доказанно
   не влияет). **ДО УСПЕШНОГО ФИТА НЕ ШИТЬ**;
2. .rpt НА АУДИТ по чек-листу шапки (п.24 + a..h): r0..r5 = 6 триггеров
   (INIT r0=SET), **r6 В НЕТЛИСТЕ НЕТ** (появился — собран исходник v3.9.8!);
   X2 = 5-ПТ OR БЕЗ инверсии (X2 регистром В ФАЗЕ r0 — БРАК); clk25_q — 1
   триггер, желательно на глобальной тактовой; por_sh 8 бит на clk 50, строб
   r0, POR 960 нс; rst/TX/FSM — clock = clk25; декодов равенства в узле НЕТ;
3. .jed → железо: осциллограф (GCK3 50 МГц; X1 120 нс duty 1/6; X2 8,33
   противофаза — два луча; CLKOUT 4,17 МГц 50%; RESET_IN низ ~0,9 мкс),
   **зазор WR#→ALE (ожидание 60..108 нс)**, серия включений, PUSH-стресс;
4. Терминал **8000 8N1**.
