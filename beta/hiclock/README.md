## Суть v3.5 (зачем)

Фит v3.4 (10:06PM 10-27) подтвердил худшее: комбинационный `assign X2 = ~X1`
фиттер снова поднял в регистр FDCPE с D = XOR(x1_q, t0_q) = D(x1_q) —
**same-D слияние: X2 В ФАЗЕ с X1** (keep на порте не помог, п.9 шапки).
Даташит ВМ85А требует противофазу; CPU не задет ( железо работает), но чиним
**ПО ПОСТРОЕНИЮ**: X2 — отдельный регистр `x2_q` с D, ОТЛИЧНЫМ от D(x1) —
same-D слияние невозможно в принципе:

| Ветка CLK_DIV | X1 | X2 (v3.5) | Почему не сольётся |
|---|---|---|---|
| 2 | `x1_q <= ~x1_q` | `x2_q <= x1_q` | D = `x1_q` != `~x1_q`; сдвиг на 1 клок = полпериода (период 2) |
| **4 (цель)** | `x1_q <= x1_q ^ t0_q` | `x2_q <= ~(x1_q ^ t0_q)` | D = XNOR != XOR; **точная противофаза с 0-го такта** (x1: 1,1,0,0…; x2: 0,0,1,1…) |
| чётные N>=6 | toggle при `cnt==MEV` | toggle при `cnt==MEV` | синхронная toggle-пара, init (1,0) — комплементарны всегда |
| нечётные (не исп.) | `X1 = x1_p ^ x1_n` | `X2 = x2_p ^ x1_n` | `x2_p` — двойник `x1_p` с инверсным INIT → `~X1` ТОЧНО, без сдвига duty |

Инициализация: `x1_q = 1`, `x2_q = 0` (POR) — противофаза с первого такта;
keep на порте X2 сохранён (страховка: сеть отдельно). Бюджет: **+1 MC** в
каждой чётной ветке, +1 MC (`x2_p`) в нечётной → прогноз фита **~95–96 MC**
(против 95 в v3.4).

## Чек-лист аудита нового .rpt (ДО прошивки)

1. Equations: X2 — регистр `x2_q` с **D = NOT(x1_q XOR t0_q)** (или XNOR-форма);
   НЕ инвертор/буфер от X1, НЕ same-D регистр с D = x1_q XOR t0_q.
2. Init: **X2 Init=RESET**, **X1 Init=SET**, t0_q Init=RESET; por-цепочка
   без изменений: `por_sh` — сдвиг (SET x8), `por_run.D = por_sh[0]`,
   Init=SET.
3. НЕТ сетей `x1_p`/`x1_n`/`cnt`/`por_cnt` и их декодов (`==0`/`!=0`)
   в целевой ветке CLK_DIV=4.
4. clk → **GCK3 единственная** GCK-сеть; **GSR/GTS = 0**.
5. Ресурсы не хуже v3.4: MC ≈ 95–96/108, PT ≈ 243–245/540, FB-входы ≤ 214/216,
   FF = 60/108 (+x2_q); **72/72 ноги по UCF** (X1 P68, X2 P69, clk P29 GCK3).
6. 0 ERROR; новые WARNING разбираются поимённо.
