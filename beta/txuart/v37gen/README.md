## Загрузка Intel HEX (v2.0.6 + клиент v1.3)

Через клиент (экран не останавливается): запустить
`xstream_view.ps1 -Port COM13`, нажать кнопку «Загрузить HEX (L)»
(или клавишу L), выбрать .hex (клиент проверит все контрольные суммы
ДО передачи), нажать B на плате (индикатор 'L'), затем OK в диалоге.
Передача 4800 8N2, 2 мс/символ + 10 мс/строка (верифицированные
настройки отчёта об отладке; большой файл идёт минуты). Успех: на
плате меню, клиент возвращается к потоку 1M. Ошибка: на плате EEEE +
SOS до Enter (Enter на плате -> меню).

Терминалом (Tera Term): порт 4800 8N2, transmit delay 2 мс/символ,
10 мс/строка, ASCII без BOM; B на плате -> отправить файл.

Тестовый образец: `fw_test_rx_ok.hex` (231 байт @8000, без CALL в
ROM - работает на v2.0.4/2.0.5/2.0.5G/2.0.6): B -> LOADM -> E=RUN ->
тройной бип ~500 Гц + FACE + строка '+ RX OK...' в окне клиента.

## Контракты софта (v37G01)

- **Джиффи**: RST 7.5 = импульс 1 клк каждые **4,096 мс** (1024 x 4 мкс,
  244,14 Гц). Кадр дисплея 16,4 мс (~61 Гц), полный цикл скана 16,4 мс,
  ISR ~170 мкс = 4,2% ЦП. (Метка «1,024 мс» в шапке RTL и Debug Report —
  арифметическая ошибка, 256 x 4 мкс — это 8 бит.)
- **IN 03h**: D7=TXRDY, D6-D5 = tmr_cnt[9:8] (медленная фаза, шаг
  1,024 мс), D4-D0 = ряды.
- **OUT**: 00h сегменты, 01h разряды+SND(A4), 04h TXDATA (строб),
  06h колонки A[7:4].
- **TMOFF/TMON/GO**: TMOFF = DI + SIM 78h; TMON = DI + SIM 78h + чистка
  + SIM 68h (7.5 снят постоянно) + EI; ISR масок не трогает. GO: ~96% ЦП
  пользователю.
- **RAMT (F)**: 8000h-FFD7h; зона FFD8h-FFE7h (стек, вкл. адрес возврата
  RAMT) не тестируется.
- **X2/BQ2**: противофазный сигнал от ПЛИС — по документации на
  ИМ1821ВМ85А (Debug Report п.2). Заметка про CA80C85B «X2 открыт» к этой
  линии не применяется. UCF-комментарий «X2 — ВХОД Hi-Z» устарел.
