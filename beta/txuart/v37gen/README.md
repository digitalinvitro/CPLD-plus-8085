## Контракты софта (v37G01)

- **Джиффи**: RST 7.5 = импульс 1 клк каждые **4,096 мс** (1024 x 4 мкс,
  244,14 Гц). Кадр дисплея 16,4 мс (~61 Гц), полный цикл скана 16,4 мс,
  ISR ~170 мкс = 4,2% ЦП. (Метка «1,024 мс» в шапке RTL и Debug Report —
  арифметическая ошибка, 256 x 4 мкс — это 8 бит.)
- **IN 03h**: D7=TXRDY, D6-D5 = tmr_cnt[9:8] (медленная фаза, шаг
  1,024 мс), D4-D0 = ряды.
- **OUT**: 00h сегменты, 01h разряды+SND(A4), 04h TXDATA (строб),
  06h колонки A[7:4].
- **TMOFF/TMON/GO**: TMOFF = DI + SIM 78h; TMON = DI + SIM 78h + чистка
  + SIM 68h (7.5 снят постоянно) + EI; ISR масок не трогает. GO: ~96% ЦП
  пользователю.
- **RAMT (F)**: 8000h-FFD7h; зона FFD8h-FFE7h (стек, вкл. адрес возврата
  RAMT) не тестируется.
- **X2/BQ2**: противофазный сигнал от ПЛИС — по документации на
  ИМ1821ВМ85А (Debug Report п.2). Заметка про CA80C85B «X2 открыт» к этой
  линии не применяется. UCF-комментарий «X2 — ВХОД Hi-Z» устарел.
