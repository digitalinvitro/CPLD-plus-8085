# beta/ — экспериментальные доработки «харда»

Папка для опытов над дизайном CPLD поверх **стабильного baseline** из `hdl/`
(`top_suart.v` v3.2, фит 2026-10-22 «POR6»: 91/108 MC, 0 WARNING/ERROR,
72/72 ноги по UCF, железо проверено в работе).

## Правила

1. `hdl/` не трогаем: baseline остаётся эталоном, от него делаются ветки.
2. Каждый эксперимент — подпапка `beta/<имя>/` со своим комплектом:
   изменённый `.v` (или патч к baseline), `.ucf` (если меняются ноги),
   отчёт фиттера `.rpt` и краткий вывод (влез / не влез / что дало).
3. В `hdl/` переезжает только то, что прошло фит без ошибок И проверку
   на железе. Откат тривиален — baseline всегда в `hdl/`.
4. Свободный ресурс baseline (целься в него, не забивай под ноль):
   **17 MC, 50 FB-входов, 315 PT**; исчерпаны FB1 (входы 36/36) и
   FB6 (макроячейки 18/18); свободные ноги: P74, P75, P76, P78, P79,
   P81, P95, P96, P98 (сейчас PGND).
